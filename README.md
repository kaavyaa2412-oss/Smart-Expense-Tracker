# Smart-Expense-Tracker

## Project Overview

Smart Expense Tracker is a simple Java-based console application designed to help users manage and monitor their daily expenses.

The application allows users to add, view, search, and delete expenses. It also provides features such as calculating total expenses, finding the highest expense, setting a monthly budget, and checking the budget status.

The project stores expense information temporarily using Java's ArrayList. No SQL or external database is required.

---

## Features

- Add a new expense
- View all expenses
- Search expenses by category
- Calculate total expenses
- Find the highest expense
- Set a monthly budget
- Check remaining budget
- Delete an expense using its ID
- Display an expense summary
- Calculate average expense
- Simple menu-driven interface
